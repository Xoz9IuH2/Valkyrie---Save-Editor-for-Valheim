TITLE
Valkyrie: How to Edit Your Valheim Character, Skills and Inventory

SHORT DESCRIPTION
A guide to Valkyrie, a standalone Windows editor for local Valheim characters: skills, inventory, backups and recovery. No BepInEx or separate .NET installation required.

BODY (STEAM MARKUP)

[h1]What is Valkyrie?[/h1]
Valkyrie is my unofficial editor for local Valheim character saves. It is a separate Windows x64 application, not a mod you install into the game.

Edit your name and existing skills, add or replace items, move them between slots and restore backups. English/Russian interfaces and light/dark themes are available.

[b]Close Valheim and make an independent backup before editing anything.[/b]

[h1]Compatibility[/h1]
[list]
[*]Windows x64.
[*]Local .fch characters. Direct Steam Cloud editing is not supported.
[*]Save formats: profile 46, player 33, inventory 109, skills 2. Unsupported formats are rejected.
[*]The item catalog is a snapshot of the game build used during development, not an automatically updated database.
[*]Modded saves are not officially supported.
[/list]
I have tested this build in-game. That does not guarantee compatibility with other Valheim updates.

[h1]1. Prepare Your Character[/h1]
If your character is in cloud storage, move it to local storage through Valheim's save-management interface. Then close the game completely.

Press Win+R and open:
[code]%USERPROFILE%\AppData\LocalLow\IronGate\Valheim\characters_local[/code]

Copy the character's .fch file to a separate backup folder outside characters_local. Do not keep multiple active copies of the same character in the game folder.

Launch Editor.exe, click [b]Open[/b] and select the original local .fch file.

[h1]2. Edit Skills[/h1]
On the [b]Skills[/b] tab, use a slider or the adjacent numeric input to set a level from 0 to 100.

Only skills already present in the save are listed. Adding missing skills is not implemented yet.

[h1]3. Manage Inventory[/h1]
A single click selects a slot. Double-click opens the item picker.
[list]
[*]Search by English/Russian name or prefab ID, such as SwordIron.
[*]Filter by weapons, armor, resources, food or other items.
[*]The left panel shows stats: description, weight, food values, and damage/armor. Leveled stats appear as 10 (+20) = 30.
[*]Set quantity with the slider or numeric input, within the catalog stack limit.
[*]Quality modes: catalog maximum, up to 99, or up to 999. Values above the in-game maximum are unverified.
[*]Click Apply. Replacing a different item requires confirmation and resets its previous properties.
[*]Use Clear slot to delete an item.
[/list]
Drag an item onto an empty cell to move it. Dropping onto an occupied cell swaps the two items.
[b]Ctrl+C[/b] copies the selected slot; [b]Ctrl+V[/b] pastes it. Occupied slots ask for confirmation.

The grid follows the save: vanilla 8x4, expanded inventories up to 8 rows. Internal variants are hidden by default. This classification is heuristic, so check the prefab ID carefully, especially when showing internal items.

[h1]4. Undo And Item Flags[/h1]
[b]Ctrl+Z[/b] or Undo reverses an edit in memory. Opening, saving or restoring a file clears the undo history.

[b]Clear cheat flags[/b] removes that marker from inventory items. Newly added items do not carry the marker. This does not clear profile-level cheat history or guarantee achievement eligibility.

[h1]5. Clean World Cheat Flags[/h1]
On the [b]World[/b] tab, select a local world, click Analyze world, then Clear cheat flags and Save world.
The editor only patches cheated items in .chunk container files and writes backups. Old single-file .db worlds and cheated items in _main.*.db2 are not cleaned. Close the game before saving.

[h1]6. Save Changes[/h1]
Make sure Valheim is closed. Click [b]Save[/b] and confirm the destination.

The editor saves into characters_local using the original filename. The previous file is retained in the [b]Backups[/b] subfolder. If the file changed externally after opening, saving is rejected; reopen the current file instead.

Launch Valheim and check your character after saving. Keep your independent backup until you have verified the result.

[h1]7. Restore A Backup[/h1]
[list=1]
[*]Close Valheim and open the local character in the editor.
[*]Click Restore backup.
[*]Select a backup from characters_local\Backups.
[*]Confirm restoration. The current on-disk save is also backed up first.
[/list]
The backup must belong to the same character and use a supported format. If a damaged save cannot be opened at all, restore your independent copy manually with the game closed, retaining the original .fch filename.

[h1]Troubleshooting[/h1]
[list]
[*]Character not found: check that it is local, not cloud-stored.
[*]Unsupported format: do not force a conversion; use a compatible editor version.
[*]Saving blocked: close Valheim and check whether the file changed since opening.
[*]An unusual item does not work: restore a backup and check its prefab ID and catalog compatibility.
[/list]
