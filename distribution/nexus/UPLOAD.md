## English Summary

Standalone Valheim character save editor for Windows x64. Edit skills and inventory with icons, search, drag-and-drop, undo and automatic backups. English/Russian interface and light/dark themes. No BepInEx or separate .NET installation required.

## Russian Summary

Автономный редактор персонажей Valheim для Windows x64: навыки, инвентарь с иконками, поиск, перетаскивание, отмена и резервные копии. Русский и английский интерфейсы, две темы. BepInEx и отдельная установка .NET не нужны.

## File Description

Windows x64 standalone beta. Extract anywhere outside the game folder and run Editor.exe. Close Valheim before saving. Supported save formats: profile 46, player 33, inventory 109, skills 2. Keep independent backups.
